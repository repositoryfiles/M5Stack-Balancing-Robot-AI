# M5Stack Balancing Robot AI

**M5Stack Core2とMicroPythonで二輪倒立振子を制御し、PD制御のデータから学習した小さなニューラルネットワークで倒立させる実験**です。

PD制御で教師データを収集し、PCのPython（scikit-learn）で学習したモデルの重み・バイアスをMicroPythonに組み込みます。最終的に、**AIのモータ指令だけで60秒間の倒立**を確認しました。実験中は指で軽く繰り返し外乱を与えています。

> **注意**：ここでいう「AI制御」は、PD制御の入出力を学習した**模倣学習**です。強化学習で倒立方法を自動発見したものではなく、PD制御より優れていることを示すものでもありません。AI実行中もPD指令を監視用に計算しています。

## 使用機器・環境

- M5Stack Core2（UIFlow2 / MicroPython）
- Roller485 Lite × 2（I2Cアドレス：`0x64`、`0x65`）
- 車輪 × 2（実験機では直径約80 mm）、自作フレーム
- Windows 11 PC、Python 3、`numpy`、`pandas`、`scikit-learn`

モータの向き、センサ軸、制御ゲイン、学習済みモデルは**実験機固有**です。別の機体で同じ動作を保証するものではありません。

## ファイル一覧

| ファイル | 役割 | 実行場所 |
| --- | --- | --- |
| `main_ai_logger_fixed.py` | PD制御で倒立し、教師データをCSVに保存 | Core2 |
| `pd_training.csv` | 実験で取得した教師データ1,000件 | PCで利用 |
| `build_ai.py` | 教師データからニューラルネットワークを学習し、重みをJSONに出力 | PC |
| `ai_weights.json` | 実験で得られた学習済みパラメータ | 参照用 |
| `main_ai_100_60s_no_csv.py` | 学習済みパラメータを組み込んだAI100%・60秒倒立プログラム | Core2 |

## 実験の流れ

### 1. PD制御で教師データを取得

Core2に `main_ai_logger_fixed.py` を転送して実行します。必要に応じてCore2側の実行ファイル名を `main.py` にします。

- 制御式：`u = -40 × theta - 1 × omega`
- 記録周期：5 ms
- 記録件数：最大1,000件（約5秒）
- 出力ファイル：`pd_training.csv`

測定データは制御中にRAMへ記録し、**モータ停止後**にCSVとして保存します。保存されたCSVをPCへコピーしてください。本リポジトリには実験時のCSVも含めています。

### 2. PCで機械学習

必要なパッケージをインストールします。

```bash
python -m pip install numpy pandas scikit-learn
```

`build_ai.py` は、入力2個（傾斜角度・角速度）、中間層4個、出力1個（モータ指令値）のニューラルネットワークを学習します。教師データの先頭80%を学習に、後半20%を評価に使い、複数の乱数シードのうち評価誤差が最小のモデルを選びます。

**実行前にファイルパスを修正してください。** 配布版 `build_ai.py` では次のように `/mnt/data/` が指定されています。

```python
p = '/mnt/data/pd_training.csv'
# ...
open('/mnt/data/ai_weights.json', 'w').write(json.dumps(weights, indent=2))
```

`build_ai.py` と `pd_training.csv` を同じフォルダに置く場合は、それぞれ `pd_training.csv` と `ai_weights.json` に変更します。その後、次を実行します。

```bash
python build_ai.py
```

学習済みの重みとバイアスが `ai_weights.json` に出力されます。掲載の `ai_weights.json` は実験で採用したモデルの値です。

### 3. Core2でAI制御

`main_ai_100_60s_no_csv.py` は、**実験で採用した重みとバイアスをプログラム内に埋め込んだもの**です。JSONをCore2上で読み込む構成ではありません。

Core2に転送して実行し、ボタンAで制御を開始します。モータ指令はAI出力から計算しますが、PD指令との差が大きい場合、傾斜角が制限を超えた場合、制御周期が異常な場合には停止する設計です。60秒版ではメモリ不足を避けるため、時系列CSVは保存せず、終了後に集計値のみ表示します。

**新たに学習した `ai_weights.json` を使う場合は、プログラム内の `AI_W1`、`AI_B1`、`AI_W2`、`AI_B2` を対応する値に置き換える必要があります。**

## AI100%制御の実験結果

| 項目 | 結果 |
| --- | ---: |
| 連続制御時間 | 60秒 |
| 制御周期（設定） | 10 ms |
| 制御回数 | 6,000回 |
| 最大制御周期 | 10.012 ms |
| 最大傾斜角度（絶対値） | 約5.22° |
| 最大モータ指令値（絶対値） | 260 |
| AIとPDの平均指令差 | 約0.362 |
| AIとPDの最大指令差 | 約2.428 |

指で細かく繰り返し外乱を与えた状態でも、60秒間倒立を維持しました。外乱の大きさは測定していないため、PD制御とAI制御の外乱抑制性能の定量比較ではありません。

## 安全上の注意

**倒立ロボットは急発進・転倒・車輪への巻き込みなどの危険があります。** 最初は車輪を浮かせ、モータの回転方向・停止動作を確認してください。周囲を片付け、外部からモータ電源を遮断できるようにしてください。ソフトウェアの停止処理は、メモリ不足や通信異常などの際に必ず成功するとは限りません。
